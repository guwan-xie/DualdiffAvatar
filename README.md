# DualDiffAvatar

This repository contains code and related data for the paper:

**DualDiffAvatar: Learning Animatable 3D Human Avatars from a Single Image via Dual Diffusion**  
Xianguo Liu, Jun Wang, Jielun Zhang, Fengkai Li, Weina Cao, Shaokun Cai

Repository: https://github.com/guwan-xie/DualdiffAvatar

---

## Description

This repository provides:

- Python scripts for training and inference of the DualDiffAvatar framework.
- Pre-processing scripts for preparing input images and multi-view observations.
- Configuration files for experiments on X-Humans and NeuMan datasets.
- Example input images and visualization scripts (planned to be uploaded after submission).

The goal is to enable reproducibility of the experiments reported in the paper, allowing users to generate animatable 3D human avatars from a single image using dual-diffusion priors.
